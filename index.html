ABOUT THIS PROJECT

ROBO INVENTOR

ROBO DRIVE X

ROBO DRIVE X is a connected robotics project developed under ROBO INVENTOR.

The project explores wireless joystick control, ESP8266 communication, vehicle monitoring, battery status display, distance measurement, signal monitoring and selectable operating modes.

The website acts as a central dashboard concept where vehicle information and system status can be viewed in one interface.
